# Business Health Monitoring System

## Project Overview

The Business Health Monitoring System is an interactive Power BI dashboard designed to monitor and analyze key business performance indicators across multiple business functions.

The project provides insights into:

- Sales Health
- Customer Health
- Employee Health
- Inventory Health
- Profit Health

It helps management make data-driven decisions using interactive dashboards and KPIs.
